# One Design System is extracted from each Mood Board

The landing page used to show three Design Systems (Clay, Grid, Soft) with their own made-up palettes, unrelated to the
Mood Boards. The Final Site actually used the Japanese Retro board's colors with Clay's fonts, so the "selected system"
documented colors that never shipped. We now extract one Design System from each Mood Board, using that board's
Palette (plus white for text on Accent or Selected), so each system captures the essence of one aesthetic and the
three look clearly different. The Selected Pair is the selected board plus its own system.

## Considered Options

- **Three independent systems with their own palettes** (the old model): the Final Site could not use both the board's
  and the system's colors, so the pairing stayed muddled.
- **Three sub-styles of the selected board**: honest pairing, but all three share six colors and look too alike.

## Consequences

- Choosing the board decides the system; "picking a pair" is one choice, not two.
- Roles live only in Design Systems; Swatches have none.
- Eigakan and the Design System pages share one component set, so restyling the selected system restyles Eigakan.
